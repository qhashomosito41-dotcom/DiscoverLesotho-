# Testing Checklist

Record the actual result of each check before submission. Do not mark an item as passed unless it has been tested.

## Page and assets
- [ ] `index.html` opens.
- [ ] Stylesheet loads.
- [ ] No JavaScript is used anywhere in the project.
- [ ] Favicon loads.
- [ ] All remote images load.
- [ ] No broken local asset paths.
- [ ] No horizontal scrolling at mobile widths.

## Navigation and CTAs
- [ ] Logo navigates to the top.
- [ ] Every desktop navigation link reaches the correct section.
- [ ] Mobile menu opens via the menu toggle link.
- [ ] Selecting a mobile navigation link closes the menu.
- [ ] The in-menu close control closes the mobile menu.
- [ ] All experience CTAs reach the enquiry form.
- [ ] Each package button links to the enquiry form.
- [ ] Back-to-top link works.

## Testimonials
- [ ] Each testimonial dot changes the sample testimonial.
- [ ] Testimonial counter updates with the selected slide.
- [ ] Testimonials are identified as fictional samples.

## Form
- [ ] Empty form is blocked by native HTML5 validation.
- [ ] A one-character name is rejected.
- [ ] Invalid email is rejected.
- [ ] Missing demonstration consent is rejected.
- [ ] Valid demo input displays a transparent message.
- [ ] No information is sent or saved.
- [ ] No real booking confirmation is displayed.
- [ ] Form controls have labels and keyboard focus.

## Responsive and accessibility
- [ ] Test around 320px width.
- [ ] Test smartphone width.
- [ ] Test tablet width.
- [ ] Test desktop width.
- [ ] Navigation is keyboard accessible.
- [ ] Focus indicators are visible.
- [ ] Images have appropriate alt text.
- [ ] Reduced-motion preference is respected.
- [ ] Text remains readable and contrast is sufficient.

## Deployment
- [ ] Site deployed to a free hosting platform.
- [ ] Public URL opens on a separate device or private browser.
- [ ] CSS, favicon, and images load in production.
- [ ] Public URL added to presentation.
- [ ] Any outstanding issues documented.
