# Development Approach and Builder Selection

## Selected approach

This project uses custom HTML5 and CSS3 only, with no JavaScript, instead of a traditional drag-and-drop website builder.

## Why this approach fits the project

- **Learning:** The code directly demonstrates how a page is structured, styled, and made interactive.
- **Control:** The group can customize layout, typography, spacing, responsive breakpoints, and interactions.
- **Lightweight delivery:** A static website does not require a framework, database, paid service, or build process.
- **Hosting:** The project can be deployed to a free static hosting platform such as GitHub Pages or Netlify.
- **Transparency:** The files are separated into HTML and CSS, making them easier to explain during a presentation.

## Technology roles

- HTML provides headings, sections, navigation, images, links, form controls, and native form validation.
- CSS provides colours, layout, typography, responsive behavior, visual states, motion preferences, and all interactions (the mobile menu uses `:target`, the testimonials use radio inputs, and form feedback uses `:target`).

## Comparison with popular builders

| Option | Strengths | Trade-offs |
|---|---|---|
| Custom HTML/CSS | Direct code control, lightweight, useful for learning core web technology, works without JavaScript | Requires the group to write and maintain code; no built-in CMS |
| WordPress | Large ecosystem, themes, plugins, content management | More setup and maintenance; hosting and plugin choices affect complexity |
| Wix | Visual editor and quick setup | Less direct control over generated code and some platform features may be paid |
| Webflow | Visual design control and responsive tools | Learning curve; some hosting and CMS features may require paid plans |
| Squarespace | Polished templates and integrated site tools | Less code-level flexibility and some features require a paid plan |

## Limitations

This static site has no database, booking engine, payment processing, real social accounts, or enquiry delivery. The enquiry form is a demonstration only. Genuine submissions require a backend or configured form service and an updated privacy notice.

## Assessment note

The assignment brief awards 15 marks for choosing the best web page builder, while also allowing a site to be built from scratch using HTML and CSS. The brief does not fully explain how that category is marked for a fully custom-coded project. The group should confirm the expected evidence with the lecturer rather than assume this approach automatically satisfies that criterion.
